# Hi, I'm Ryan Vandersmith.

R&D software engineer building forecasting, visualization, and analysis tools for meteorology and atmospheric science. Based in Amherst, Massachusetts.

## Experience

Over 10 years of professional software engineering with a self-taught background in meteorology.

- **DFINITY Foundation** (2022 - 2026): Led Motoko programming-language tooling (including a VS Code extension with 85,000+ installs), cross-chain EVM integrations, and developer-experience products. Contributed to Caffeine.ai, an AI website builder.
- **Plexa Technologies** (2017 - 2022): Full-stack Progressive Web Apps and custom web products for startups and small businesses.
- **University of Colorado Boulder** (2018): Rust visualization tool for research on typed incremental computation (Adapton).
- **Douglas County School District** (2014 - 2017): Bus tracking and route viewer, REST APIs, CI/CD improvements, and mentorship of the software intern team.
